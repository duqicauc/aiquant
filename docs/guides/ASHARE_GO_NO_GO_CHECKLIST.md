# A股实盘准入清单（Go/No-Go）

适用对象：`v232_v270` 互补策略接入 `miniqmt` 的模拟盘与实盘流程。  
使用原则：先满足回测准入，再满足模拟盘准入，最后进入小资金实盘灰度。

---

## 1. 回测准入（进入模拟盘前）

### 1.1 收益与稳健性
- [ ] 最近滚动 3 个月超额收益 > 0（对比沪深300）
- [ ] 信息比率 IR > 0
- [ ] 至少 2/3 月份跑赢基准
- [ ] Walk-forward 失败窗口占比 < 30%

### 1.2 风险约束
- [ ] 成本后最大回撤 `MaxDD <= 12%`（可在 10%-15% 内按风险偏好调整）
- [ ] 单日收益分布 `P99 >= -3.5%`
- [ ] 连续亏损交易笔数 <= 8

### 1.3 可成交与成本
- [ ] 不可成交建模已启用（涨跌停/停牌/成交量约束/集合竞价偏离）
- [ ] 成交率 >= 85%
- [ ] 未成交原因可归因率 = 100%
- [ ] 成本后收益仍为正，且收益衰减不超过 35%

---

## 2. 模拟盘准入（进入实盘灰度前）

### 2.1 执行质量
- [ ] 计划单 -> 已报成功率 >= 99%
- [ ] 已报 -> 最终成交率 >= 85%
- [ ] 撤改单超时处理成功率 >= 95%
- [ ] 订单状态机覆盖完整：未报/已报/部成/全成/已撤/废单

### 2.2 价格偏差与滑点
- [ ] 买入成交偏差中位数 <= 25bp
- [ ] 卖出成交偏差中位数 <= 30bp
- [ ] 重大偏差（>100bp）有逐笔归因与规则修正方案

### 2.3 风控与一致性
- [ ] 单票、单板块、单日亏损、组合回撤风控已生效
- [ ] 熔断触发后行为正确：仅减仓不加仓
- [ ] 收盘三方对账一致（券商持仓/本地账本/策略预期）
- [ ] 对账异常可在当日闭环（自动修复或人工确认）

---

## 3. 小资金实盘灰度准入（进入放量前）

### 3.1 灰度范围
- [ ] 目标仓位 5%-10%
- [ ] 连续运行 >= 20 个交易日
- [ ] 关键交易日（波动放大日）无严重执行事故

### 3.2 收益风险
- [ ] 灰度期超额收益 >= 0
- [ ] 灰度期 `MaxDD <= 6%`
- [ ] 单日回撤不超过策略红线（建议 <= 3%）

### 3.3 稳定性
- [ ] 交易时段关键任务成功率 >= 99%
- [ ] 无重复下单、漏撤单、状态错乱
- [ ] 网络/接口异常时降级策略触发成功率 = 100%

---

## 4. 放量实盘条件

- [ ] 连续 2 个灰度周期均通过第 3 章检查
- [ ] 成交偏差与漏成交率无恶化趋势
- [ ] 风控、对账、告警均通过演练并留痕

---

## 5. 一票否决（任一触发即 No-Go）

- [ ] 对账出现不可解释差异
- [ ] 风控触发后出现加仓
- [ ] 单日实际回撤突破红线
- [ ] 出现重复下单或持仓错账
- [ ] 生产环境关键任务失败且无自动恢复

---

## 6. 日常运维检查项

### 6.1 每日检查（收盘后）
- [ ] 交易日志完整归档（信号价/委托价/成交价/未成交原因）
- [ ] 当日风控触发记录已审阅
- [ ] 三方对账完成并签字确认
- [ ] 次日风险提示已生成（集中度、高波动持仓、流动性风险）

### 6.2 每周复盘
- [ ] 统计周度超额、回撤、胜率、换手
- [ ] 复盘重大偏差单，更新执行参数
- [ ] 复核策略参数是否漂移
- [ ] 更新 Go/No-Go 状态：`GO` / `CONDITIONAL_GO` / `NO_GO`

### 6.3 放量审批（阶段性）
- [ ] 评审材料齐全（收益风险、执行质量、风控记录、异常报告）
- [ ] 评审结论明确（通过/附条件通过/拒绝）
- [ ] 下一阶段资金上限、撤回条件、观察期明确

---

## 7. 建议数据看板字段（Web 页面）

- [ ] 当日执行质量：计划单数、成交数、漏成交率、原因分布
- [ ] 风控状态：触发次数、触发规则、影响仓位
- [ ] 对账状态：一致/不一致、差异金额、修复状态
- [ ] 成交偏差：买卖偏差中位数、尾部偏差（P95/P99）
- [ ] 策略表现：当日收益、滚动回撤、滚动超额、换手率

---

## 8. 版本与维护

- 文档版本：`v1.0`
- 维护人：策略负责人 + 交易执行负责人
- 更新频率：每月至少一次，或在交易规则/风控规则重大变更后立即更新

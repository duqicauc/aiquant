# 技术分析深化指南

## 概述

本指南介绍 AIQuant v5.0 新增的技术分析体系，包含 **量价分析**、**高级趋势指标**、**多周期共振（MTFA）** 和 **主力资金行为分析** 四大模块。

> **设计哲学**：v2.9.1/v2.9.2/v2.7.0 等模型已经承担了机器学习信号融合（思路E）的角色。本补充方案聚焦 **B（多周期共振）+ C（主力资金）**，作为模型预测的人工验证层。

## 一、指标体系总览

### 1.1 量价分析（6个指标）

| 指标 | 核心含义 | 实战应用 |
|------|---------|---------|
| **VWAP** | 成交量加权平均价，机构成本线 | 价格 > VWAP = 强于机构成本，持仓；价格 < VWAP = 弱于成本，警惕 |
| **CMF** | Chaikin Money Flow，资金流向强度 | >0.05 资金流入，<-0.05 流出；关注**底背离**（价格跌、CMF升） |
| **MFI** | Money Flow Index，量价RSI | >80 量价超买（警惕），<20 量价超卖（机会）；比RSI更可靠 |
| **PVO** | Percentage Volume Oscillator | 量能MACD；金叉 = 成交量趋势转强，适合追涨；死叉 = 量能萎缩，警惕 |
| **A/D Line** | 累积/派发线 | 上升趋势确认资金在累积；**顶背离**（价格新高、AD线不新高）= 危险信号 |
| **Volume Profile** | 成交量价格分布 | POC（最大成交量价）= 主力成本区；Value Area = 70%筹码区；价格突破VA上下轨 = 变盘 |

### 1.2 高级趋势指标（5个指标）

| 指标 | 核心含义 | 实战应用 |
|------|---------|---------|
| **ADX/DMI** | 趋势强度 + 方向 | ADX > 25 趋势强，+DI 上穿 -DI = 多头启动；ADX < 20 震荡市，减少操作 |
| **SuperTrend** | ATR通道趋势跟踪 | A股效果极好的趋势指标；绿转红 = 买入，红转绿 = 卖出；顺势持仓 |
| **Ichimoku** | 一目均衡表（日本综合指标） | 云上方 + Tenkan>Kijun = 强烈看涨；云中 = 震荡；云下方 = 看跌 |
| **SAR** | 抛物线转向 | 点翻转 = 趋势反转信号；适合止损位设定 |
| **ATR Channel** | ATR波动率通道 | 突破上轨 = 波动率扩张（可能 breakout）；接近下轨 = 低吸机会 |

### 1.3 形态识别（替代波浪理论）

| 形态 | 识别规则 | 交易逻辑 |
|------|---------|---------|
| **谐波形态** | 加特利/蝴蝶/螃蟹/蝙蝠，基于斐波那契比例 | D点入场，预设目标位和止损位，风险回报比清晰 |
| **分形（Fractals）** | 比尔·威廉姆斯5根K线分形 | 分形高点 = 潜在压力，分形低点 = 潜在支撑；突破分形 = 趋势延续 |

> **为什么不自动识别艾略特波浪？** 波浪理论主观性极强，同一张图不同分析师数出完全不同的浪型。自动化识别的误报率 >50%，反而误导用户。谐波形态有**明确的数学比例规则**，更适合程序化实现。

## 二、多周期共振（MTFA）使用方法

### 2.1 核心逻辑

单一周期指标容易发出假信号。当 **日线、周线、月线** 同时发出同向信号时，信号可靠性大幅提升。

**共振评分规则**：
- 日线权重 50%、周线 30%、月线 20%
- 各周期计算 RSI/MACD/均线/布林带/偏离MA20 五项指标，每项 0-10 分
- 周期同向 + 分数都高 = 共振 bonus；周期冲突 = 扣分

### 2.2 实战解读

| 场景 | 日线 | 周线 | 月线 | 综合建议 |
|------|------|------|------|---------|
| 三级共振买入 | RSI超卖+MACD金叉 | 多头排列 | 布林下轨 | **强烈买入** |
| 二级共振 | RSI中性+MACD多头 | 均线多头排列 | — | **买入** |
| 周期冲突 | RSI超买（日线要跌） | 多头排列（周线要涨） | — | **观望**，等待日线回调到位 |
| 三级共振卖出 | RSI超买+MACD死叉 | 空头排列 | 布林上轨 | **强烈卖出** |

### 2.3 使用入口

- **Dashboard**：股票研究页 → "🔔 多周期共振" 面板
- **API**：`GET /api/stock/{ts_code}/advanced-indicators?period=daily`

## 三、主力资金行为分析使用方法

### 3.1 核心洞察

A股是散户主导市场，**资金流向比技术指标更有预测力**。

| 信号 | 含义 | 操作建议 |
|------|------|---------|
| 特大单连续净流入 | 机构建仓/加仓 | 跟随 |
| 小单净流入 + 股价跌 | 散户恐慌接盘，主力在出 | **反向**：等散户割完再进 |
| 小单净流出 + 股价跌 | 散户恐慌割肉 | **反向**：可能是底部 |
| 小单净流入 + 股价涨 | 散户追涨 | **警惕**：顶部风险 |
| 大单卖出但股价上涨 | 游资接力 | 短线机会，但注意退潮 |

### 3.2 散户反向指标逻辑

散户行为往往是反向指标：
- 散户恐慌割肉（小单净卖出 + 大跌）→ 市场底部
- 散户狂热追涨（小单净买入 + 大涨）→ 市场顶部
- **当散户情绪达到极端时，反向操作胜率最高**

### 3.3 使用入口

- **Dashboard**：股票研究页 → "💰 主力资金" 面板
- **API**：`GET /api/stock/{ts_code}/advanced-indicators`（包含 moneyflow 字段）

> **注意**：资金流向数据需要 Tushare 积分权限（`moneyflow` 接口）。如果积分不足，面板会提示"数据暂不可用"。

### 4.2 指标卡片颜色含义

- **绿色** =  bullish/买入/流入/强势
- **红色** =  bearish/卖出/流出/弱势
- **黄色** =  中性/震荡/观望

### 4.3 多周期切换

点击 **日线/周线/月线** 按钮切换周期：
- **日线**：适合短线交易，信号多但假信号也多
- **周线**：过滤噪音，适合波段操作（推荐）
- **月线**：大周期趋势，适合长线配置

> **最佳实践**：周线定方向，日线找买点，月线验大趋势。

## 五、API 使用示例

### 5.1 获取全部高级指标

```bash
curl "http://localhost:8000/api/stock/000001.SZ/advanced-indicators?days=120"
```

### 5.2 只获取指定指标

```bash
curl "http://localhost:8000/api/stock/000001.SZ/advanced-indicators?days=120&indicators=vwap,cmf,adx_dmi,supertrend"
```

### 5.3 获取周线数据

```bash
curl "http://localhost:8000/api/stock/000001.SZ/advanced-indicators?days=120&period=weekly&indicators=adx_dmi,supertrend"
```

### 5.4 Python 调用示例

```python
import requests

# 获取多周期共振 + 主力资金
resp = requests.get(
    "http://localhost:8000/api/stock/600519.SH/advanced-indicators",
    params={"days": 120, "period": "daily"}
)
data = resp.json()

# 共振评分
print("共振评分:", data["mtfa"]["overall_score"])
print("建议:", data["mtfa"]["recommendation"])

# 主力资金
print("主力动向:", data["moneyflow"]["main_force"]["signal"])
print("散户信号:", data["moneyflow"]["retail_contrarian"]["signal"])

# VWAP 位置
print("VWAP:", data["indicators"]["vwap"]["value"])
print("偏离:", data["indicators"]["vwap"]["distance_pct"], "%")

# SuperTrend
print("SuperTrend:", data["indicators"]["supertrend"]["signal"])
```

## 六、交易策略组合建议

### 6.1 高胜率买入组合

需要同时满足：
1. **MTFA 共振评分 ≥ 70**（多周期偏多）
2. **SuperTrend 转多** 或 **Ichimoku 云上方**
3. **CMF > 0.05** 或 **A/D Line 底背离**（资金在流入）
4. **散户恐慌割肉**（小单净卖出 + 大跌）
5. **MFI < 30** 或 **RSI < 30**（超卖区）

### 6.2 高胜率卖出组合

需要同时满足：
1. **MTFA 共振评分 ≤ 30**（多周期偏空）
2. **SuperTrend 转空** 或 **SAR 翻转向下**
3. **CMF < -0.05**（资金流出）
4. **散户狂热追涨**（小单净买入 + 大涨）
5. **MFI > 80** 或 **RSI > 70**（超买区）

### 6.3 与模型预测的互补使用

| 模型预测 | 技术分析验证 | 操作建议 |
|---------|------------|---------|
| 模型看涨 + MTFA ≥ 70 + 资金流入 | 共振确认 | **重仓买入** |
| 模型看涨 + MTFA < 55 + 资金流出 | 技术不支持 | **轻仓试探** 或 **等待回调** |
| 模型看跌 + MTFA ≤ 30 + 资金流出 | 共振确认 | **清仓/做空** |
| 模型看跌 + MTFA > 55 + 资金流入 | 技术不支持 | **观望**，可能模型滞后 |

> **关键原则**：模型预测 + 技术验证 **方向一致** = 高置信交易；**方向冲突** = 降低仓位或观望。

## 七、常见问题

**Q: 为什么不做艾略特波浪自动识别？**
A: 波浪理论主观性太强，自动化识别的准确率 <60%，容易误导。谐波形态有明确的斐波那契数学规则，更适合程序化实现。

**Q: 资金流向数据为什么有时不可用？**
A: Tushare `moneyflow` 接口需要积分权限。如果积分不足，Dashboard 会显示"数据暂不可用"。其他指标不受影响。

**Q: SuperTrend 参数怎么调？**
A: 默认 period=10, multiplier=3。A股波动大，可以调大 multiplier（如 3.5）减少假信号；美股可以调小（如 2.5）增加灵敏度。

**Q: 多周期共振评分多少算高？**
A: ≥80 强烈看涨，65-79 买入，45-64 震荡，20-44 卖出，<20 强烈卖出。

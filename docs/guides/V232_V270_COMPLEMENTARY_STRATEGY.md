# v2.3.2 与 v2.7.0 互补策略使用指南

## 📋 策略概述

### 问题背景

- **v2.7.0模型**：稳定、风险控制好，但可能错过近期热门板块的强势龙头股
- **v2.3.2模型**：能捕捉热门板块龙头股（人形机器人、可控核聚变、AI应用、存储、电力、商业航天等），但有追高风险

### 互补策略核心思路

**策略4：互补策略（推荐）**

1. **v2.7.0作为稳定基础池**（Top50）
   - 提供稳健标的，确保组合的稳定性
   - 默认低风险等级

2. **v2.3.2作为热门板块补充**（Top100候选池）
   - 捕捉强势龙头股
   - 自动识别热门板块（人形机器人、可控核聚变、AI应用、存储、电力、商业航天等）

3. **风险分层管理**
   - 低风险：优先选择，无数量限制
   - 中风险：最多5只（可配置）
   - 高风险：最多3只（可配置）

4. **热门板块识别与加权**
   - 自动识别热门板块股票
   - 热门板块股票获得+0.1的得分加成
   - 优先推荐热门板块股票

5. **综合得分计算**
   - v2.7.0股票：使用v2.7.0概率
   - v2.3.2股票：v2.7.0权重0.4 + v2.3.2权重0.6 + 热门板块加成 - 风险调整

## 🚀 使用方法

### 基本用法

```bash
# 使用互补策略（默认策略）
python scripts/combine_v232_v270.py --date 20260116 --strategy complementary --top 10
```

### 完整参数

```bash
python scripts/combine_v232_v270.py \
  --date 20260116 \
  --strategy complementary \
  --top 10 \
  --base-top-n 50 \
  --v232-top-n 100 \
  --max-high-risk 3 \
  --max-medium-risk 5 \
  --fundamental
```

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--date` | 必填 | 预测日期 (YYYYMMDD) |
| `--strategy` | `complementary` | 策略类型：`complementary`（互补策略） |
| `--top` | `10` | 输出TopN股票 |
| `--base-top-n` | `50` | v2.7.0稳定基础池数量 |
| `--v232-top-n` | `100` | v2.3.2候选池数量 |
| `--max-high-risk` | `3` | 最多包含的高风险股票数 |
| `--max-medium-risk` | `5` | 最多包含的中风险股票数 |
| `--fundamental` | 否 | 启用基本面筛选 |

| `v232_score` / `v232_prob` | v2.3.2模型评分/概率 |

### 风险等级判定标准

**高风险（high）**：满足以下任一条件
- 当日涨幅 > 15%
- RSI > 95
- 连续涨停 ≥ 3天
- 惩罚系数 < 0.5

**中风险（medium）**：满足以下任一条件
- 当日涨幅 10-15%
- RSI 90-95
- 连续涨停 2天
- 惩罚系数 0.5-0.7

**低风险（low）**：其他情况

### 热门板块识别

**优先使用同花顺热榜数据**（推荐，只需6000积分）：
- 从Tushare获取同花顺App热榜数据（`ths_hot`接口）
- 获取热门概念板块（包含热度值、涨跌幅、排名、上榜解读）
- 获取热门行业板块（包含热度值、涨跌幅、排名）
- 获取热门股票（用于交叉验证）
- 自动识别属于这些热点板块的股票
- 显示板块热度信息（热度值、涨幅、排名等）

**备选方案**（如果同花顺热榜获取失败）：
- 使用`limit_cpt_list`获取最强板块统计（需要8000积分）
- 使用`sw_daily`获取申万行业涨幅（需要5000积分）

**备选方案**（如果Tushare数据获取失败）：
- 使用关键词匹配识别以下热门板块：
  1. **人形机器人**：机器人、人形机器人、智能机器人、服务机器人
  2. **可控核聚变**：核聚变、可控核聚变、核能、核反应
  3. **AI应用**：人工智能、AI、大模型、ChatGPT、AIGC、生成式AI、机器学习
  4. **存储**：存储、存储器、闪存、DRAM、NAND、内存
  5. **电力**：电力、新能源、光伏、风电、储能、特高压、智能电网
  6. **商业航天**：航天、卫星、商业航天、火箭、空间站、北斗

## 📈 策略优势

1. **兼顾稳定性与收益性**
   - v2.7.0提供稳定基础
   - v2.3.2捕捉热门机会

2. **智能风险控制**
   - 自动风险分层
   - 严格控制高风险股票数量
   - 优先推荐低风险标的

3. **热门板块自动识别（已优化）**
   - **使用同花顺热榜数据**（只需6000积分，数据更丰富）
   - 实时获取当日热门概念和行业板块
   - 包含热度值、涨跌幅、排名、上榜解读等详细信息
   - 自动识别属于这些热点板块的股票
   - 热门板块股票获得额外权重
   - 备选方案：如果数据获取失败，自动降级到关键词匹配

4. **灵活配置**
   - 可根据风险偏好调整参数
   - 支持基本面筛选
   - 可控制各风险等级股票数量

---

## ⚠️ 注意事项

1. **数据依赖**
   - 需要同时有v2.3.2和v2.7.0的预测结果
   - v2.3.2结果文件：`v2.3.2_full_{date}.csv`
   - v2.7.0结果文件：`v270_ensemble_all_{date}.csv`

2. **概念信息获取**
   - 需要Tushare API权限
   - **推荐积分≥6000**：可使用同花顺热榜接口（`ths_hot`），数据更丰富
   - 备选方案：≥8000积分可使用`limit_cpt_list`接口
   - 如果Tushare热点板块数据获取失败，会自动降级到关键词匹配方案

3. **风险提示**
   - 高风险股票虽然可能带来高收益，但也存在较大回撤风险
   - 建议根据自身风险承受能力调整参数
   - 建议结合基本面筛选使用

4. **定期评估**
   - 建议定期回顾策略表现
   - 根据市场情况调整参数
   - 关注热门板块的变化

## 🔄 与其他策略对比

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **互补策略** | 兼顾稳定性与收益性，自动识别热门板块，风险分层 | 需要两个模型结果 | **推荐：日常使用** |
| 交集策略 | 两个模型都看好，风险低 | 可能错过热门板块 | 保守型投资者 |
| 加权策略 | 简单直接 | 无法识别热门板块，无风险分层 | 简单场景 |
| 排名策略 | 综合考虑两个模型排名 | 无法识别热门板块，无风险分层 | 排名敏感场景 |

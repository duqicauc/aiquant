## 2. v291 强势来源分析

### 2.1 模型架构：Ensemble 是核心优势

| 子模型 | AUC | 权重 |
|--------|-----|------|
| XGBoost | 0.9692 | 33.2% |
| LightGBM | 0.9763 | 33.4% |
| CatBoost | 0.9776 | 33.4% |
| **Ensemble** | **0.9663** | — |

**关键洞察**: Ensemble 的加权平均天然分散了概率分布：
- v291 Top10 prob_std = **0.0170**
- v292-激进 Top10 prob_raw_std = **0.0003**
- v292-保守 Top10 prob_raw_std = **0.0115**

概率分布分散 → sector filter 的 boost 能有效改变排名 → integrated 策略收益最大化

### 2.2 训练数据质量

| 指标 | v291 | v292-cons |
|------|------|-----------|
| Hard negative ratio | **18%** (控制上限) | 11.6% |
| 特征数 | 167 | 173 |
| scale_pos_weight | **动态计算** | 固定 |
| 数据来源 | 多版本融合 (v5 enhanced + v5 features) | 统一 enhanced |

v291 的高硬负比例使模型更"谨慎"，输出概率更分散。

### 2.3 选股风格：小盘追涨

| 特征 | v291 | v292-cons | 影响 |
|------|------|-----------|------|
| 市值 | 20-23亿 | 43-127亿 | 2024Q4牛市中小盘股涨幅更大 |
| 涨跌幅 | 5.27% | 2.65% | v291更追涨，牛市中更占优 |
| 选股重叠率 | — | 10% | 两者选股完全不同 |

### 2.4 Sector Filter 兼容性

sector filter 的核心逻辑：`adjusted_score = prob × sector_boost`

| 版本 | prob 均值 | prob std | 与 sector filter 兼容性 |
|------|----------|----------|----------------------|
| v291 | 0.887 | **0.017** | ✅ 最佳 |
| v292-激进 | 0.999 | 0.0003 | ⚠️ 可改变排名但模型弱 |
| v292-保守 | 0.980 | **0.002** (Platt) | ❌ 灾难性 |
| v292-保守 | 0.961 | **0.012** (raw) | ⚠️ 可改善但仍不足 |

**实验证明**: v292-cons 在 integrated 策略下使用 prob_raw 排序，收益从 +1.90% 提升到 +5.24%（+3.3%），但仍远低于 v291。

## 3. v292 失败根因

### 3.1 单模型概率过度集中

CatBoost 单模型在硬负样本不足时，倾向于输出极端概率（0.999+）。

### 3.2 Platt Scaling 加剧问题

Platt Scaling 参数 a=-8.76, b=4.52 使 sigmoid 在 0.96 附近极度陡峭：
- prob_raw std = 0.0115
- prob_cal (Platt) std = **0.0019**

在 integrated 策略下使用 prob 排序时，sector filter 几乎失效。

### 3.3 硬负样本不足

11.6% 的硬负比例低于 v291 的 18%，导致模型过度自信。

### 3.4 大盘稳健风格

43-127亿的市值偏好在 2024Q4 牛市中严重吃亏。

## 4. 决策建议

### 4.1 立即执行

✅ **继续使用 v2.9.1-ensemble + integrated 作为主力策略**

当前 current.json 已更新：
- testing: v2.9.1-ensemble
- development: v2.9.2-catboost-conservative（研究分支）

### 4.2 短期优化（本周）

1. **修复 v292 的 Platt Scaling 问题**
   - 在 integrated 策略下使用 prob_raw 排序（已验证可提升 +3.3%）
   - 或改用 IsotonicRegression（如 v291）

2. **提升硬负样本比例**
   - 将 v292 的 hard negative ratio 从 11.6% 提升到 18%
   - 使用 v291 同源的硬负样本数据

3. **尝试 Ensemble 复刻**
   - 用 v292 的训练数据重新训练 XGB + LGB + CatBoost ensemble
   - 观察是否能达到 v291 的水平

### 4.3 中期探索（本月）

1. **模型-策略联合优化**
   - 训练时直接以 integrated 策略的回测收益为目标
   - 而非单纯优化 AUC

2. **风格适配**
   - 研究如何在模型层面控制市值偏好
   - 或通过后处理过滤（如排除 >100亿大盘股）

### 4.4 关键认知

> **策略差异 > 模型差异**
>
> v291 同一模型：integrated +18.10% vs realistic -13.21%（差距 31%）
>
> 选择正确的策略比选择正确的模型更重要。

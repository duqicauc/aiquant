> **前提约束**: 暂不考虑对外付费订阅/收费荐股模式，基于中国证券合规要求评估。

## 二、关键缺失识别

### 2.1 交易闭环缺失（最大 Gap）

```
前端路由: /trading → Trading.tsx
实际内容: <Empty description="实盘交易功能开发中" />
```

- **MiniQMT 接入**：`src/trading/miniqmt_adapter.py` 仅为桩代码，需本机 `xtquant`
- **风控引擎**：极简风控（15% 回撤强制降仓）已放弃，实盘无有效风控
- **对账体系**：`src/trading/reconcile.py` 存在但未经实盘验证
- **订单状态机**：未完整覆盖 未报/已报/部成/全成/已撤/废单

**结论**：系统目前是一个「信号工厂」，不是「交易工厂」。从信号到成交，Gap 极大。

## 三、业务风险评估

### 3.1 合规风险（红色）

**对外收费的绝对禁区**：
- 《证券法》第 160 条：未取得投顾资格，不得向客户提供投资建议并收取费用
- 《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》：算法荐股属于投顾业务
- 即使包装为「软件订阅」「数据服务」，实质是荐股的，监管部门可穿透认定

**自用自动化的灰色地带**：
- 个人账户使用 MiniQMT/Ptrade 自动化交易，券商通常默许
- 但监管态度趋严，高频/异常交易可能被监控
- 建议：保持低频（日级/周级），避免触发异常交易预警

### 3.2 技术风险（橙色）

| 风险点 | 等级 | 说明 |
|--------|------|------|
| **单数据源依赖** | 🔴 高 | 100% 依赖 Tushare Pro，若 API 涨价/断供/数据出错，系统瘫痪 |
| **模型过拟合** | 🟡 中 | AUC 0.9663 过高，需警惕是否在特定市场结构下拟合。2025Q1 胜率仅 38.8% 说明模型在震荡市已出现适应性下降 |
| **策略容量限制** | 🟡 中 | v270 底部放量策略依赖小盘股流动性，资金容量有限（预估 < 500 万）|
| **黑天鹅失效** | 🟡 中 | 2020 年以前数据训练，2020 年后的极端事件（如 2024 年初流动性危机）覆盖不足 |

### 3.3 市场风险（橙色）

- **收益衰减**：回测表现优异的策略，在实盘公开后会被市场快速套利
- **竞争壁垒低**：XGBoost + 技术指标的特征组合，技术门槛不高，竞品容易复制
- **市场环境变化**：2025Q1 的「假强牛+热点轮动快」已成为策略盲区，未来可能出现新的盲区

### 3.4 运营风险（黄色）

- **单人项目**：所有核心逻辑、参数调优、异常处理依赖一人，存在「 bus factor = 1 」风险
- **测试缺失**：无单元测试、无集成测试、无回归测试，任何代码改动都可能导致生产故障
- **版本混乱**：CHANGELOG 与代码实际版本脱节（文档 2.9.1 vs 代码 2.9.3）

## 四、交易执行模式对比（自用场景）

| 维度 | 自动化实盘 | 人工跟单（推荐） |
|------|-----------|----------------|
| **技术门槛** | 高。需补齐 MiniQMT 接入、风控、对账、状态机 | **低**。现有面板已可直接查看信号 |
| **合规风险** | 中。个人账户自动化属灰色地带 | **极低**。完全自主决策，无合规争议 |
| **执行纪律** | 100%。无情绪、无拖延、无遗漏 | 依赖个人。需建立严格交易纪律 |
| **系统匹配度** | 差。`Trading.tsx` 仅为占位，Gap > 2 个月开发量 | **好**。预测 + 回测 + 监控面板已可用 |
| **资金门槛** | MiniQMT 通常需 50 万+ 资产 | 无 |
| **综合推荐度** | ⭐⭐ | **⭐⭐⭐⭐⭐** |

### 推荐方案：人工跟单 + 半自动化辅助

```
每日收盘后 → 系统自动生成预测报告（Top 10 推荐）
     ↓
用户审阅报告 + 结合基本面判断 → 手动下单
     ↓
次日开盘/盘中执行买入
     ↓
持仓期间 → 系统每日生成持仓体检 + 卖出信号提醒
     ↓
用户决策是否卖出
```

**理由**：
1. 现有系统 90% 的价值已在「信号生成」端，无需为剩余的 10% 投入巨大开发成本
2. 人工决策可过滤模型的「盲区」（如 2025Q1 的假强牛）
3. 完全规避合规风险
4. 可立即开始产生实际收益，无需等待开发

## 五、间接变现路径（在不对外收费的前提下）

### 5.1 内容/IP 输出（可行性：高）

- **量化投资博客/公众号**：分享策略逻辑、回测方法、避坑经验
- **视频/播客**：「我是如何构建 A 股量化系统的」系列
- **知识付费课程**：教「如何构建量化系统」而非「买什么股票」（规避荐股合规风险）

> 关键区别：卖「渔具」合法，卖「鱼」需牌照。

### 5.2 技术能力展示（可行性：高）

- **求职作品集**：AUC 0.9663、+38% 回测收益、完整工程管线，是极强的技术背书
- **技术咨询**：为金融机构/私募提供量化系统架构咨询（不直接提供策略信号）
- **开源项目**：开源部分框架（如数据管线、回测引擎），建立技术影响力

### 5.3 白标技术输出（可行性：中）

- 将系统框架授权给持牌机构（券商、投顾公司、私募）
- 对方提供牌照和合规，你提供技术
- **前提**：需补充 LICENSE 文件，明确知识产权归属

### 5.4 自有资金资管（可行性：中）

- 用系统管理自有资金，追求年化 15-25% 收益
- 资金规模达到一定程度后，可考虑成立私募（需 1000 万注册资本 + 基金从业资格）
- 这是从「自用」到「合规对外收费」的最干净路径

## 六、总结与优先级建议

### 6.1 价值总结

AIQuant 是一个**技术资产扎实、工程化程度高、但商业模式未完成闭环**的量化系统。其核心资产（v2.9.3 模型、双策略架构、自动化管线）在「信号生成」端已达到生产级水平，但在「交易执行」端和「合规资质」端存在显著缺口。

### 6.2 行动优先级

| 优先级 | 行动 | 预期收益 | 投入成本 |
|--------|------|----------|----------|
| **P0** | **立即启用人工跟单模式** | 立即开始产生实盘收益 | 零 |
| **P1** | **补充 LICENSE 文件** | 保护知识产权，为 future 授权/开源铺路 | 1 小时 |
| **P2** | **建立交易纪律 SOP** | 降低人工执行的纪律损耗 | 2-4 小时 |
| **P3** | **内容输出（博客/视频）** | 建立个人 IP，间接变现 | 持续投入 |
| **P4** | **补齐测试覆盖** | 降低维护风险，便于迭代 | 1-2 周 |
| **P5** | **评估实盘自动化** | 长期提升执行效率 | 1-2 月 |
| **P6** | **申请投顾/基金资质** | 唯一合规对外收费路径 | 6-12 月 + 资金 |

### 6.3 一句话结论

> **AIQuant 当前最大的商业价值，不是「卖给别人用」，而是「帮自己赚钱」—— 以人工跟单模式立即启动实盘，同时通过内容输出和技术展示积累间接收益，长远看以自有资金规模化为目标，逐步走向合规持牌。**

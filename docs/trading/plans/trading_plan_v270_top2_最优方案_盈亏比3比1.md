## ⚠️ 风险提示与免责声明

### 主要风险

1. **市场风险**
   - 大盘系统性下跌可能导致所有股票下跌
   - 无法保证建仓价位一定能成交
   - 可能出现连续下跌无法止损的情况

2. **流动性风险**
   - 部分股票成交量较小，可能无法快速成交
   - 跌停时卖单较多，可能排队卖出
   - 建仓时买单较多，可能无法按预期价格成交

3. **操作风险**
   - 情绪化操作可能导致不按计划执行
   - 贪婪心理可能导致错过止盈时机
   - 恐惧心理可能导致过早止损
   - **止损更严格（-4%），需要更强的执行力**

4. **技术风险**
   - 交易系统故障可能影响操作
   - 网络中断可能错过最佳时机
   - 条件单可能因系统问题未执行

### 应对预案

**如遇连续下跌怎么办？**
```
1. 严格执行止损位（-4%），不要犹豫
2. 不要补仓摊平成本
3. 如触发强制止损，立即清仓
4. 保持冷静，不要恐慌性操作
```

**如遇大盘暴跌怎么办？**
```
1. 所有止损位下调1-2%（如从-4%调整到-5%）
2. 优先止损亏损较大的股票
3. 盈利股票至少减仓50%
4. 不要恐慌性全部清仓，但要控制风险
```

**如上班时间无法操作怎么办？**
```
1. 提前设置条件单，让系统自动执行
2. 中午休息时检查一下价格和条件单
3. 收盘后检查一下持仓情况
4. 如果条件单未执行，收盘后手动操作
```

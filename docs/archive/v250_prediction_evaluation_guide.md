# v2.5.0模型预测与评估指南

## 📋 操作步骤

### 步骤1: 运行v2.5.0模型预测

```bash
# 预测2025.12.31的Top10股票
python scripts/predict_v250_top10.py --date 20251231
```

**注意**: 如果遇到权限问题，需要：
1. 确保有网络访问权限
2. 确保Tushare token配置正确
3. 可能需要使用 `required_permissions: ['all']` 运行

### 步骤2: 运行评估对比脚本

```bash
# 评估v2.5.0 vs v2.3.1的预测效果
python scripts/evaluate_v250_vs_v231.py
```

这个脚本会：
1. 读取v2.5.0的预测结果（`data/prediction/results/v2.5.0_top10_20251231.csv`）
2. 读取v2.3.1的预测结果（`data/prediction/results/v2.3.1_top10_20251231.csv`）
3. 获取2026.01.14的实际收盘数据
4. 计算每只股票的实际收益
5. 生成对比报告

### 步骤3: 查看评估结果

评估结果会保存在：
- 控制台输出：详细的对比信息
- 报告文件：`data/prediction/evaluation/v250_vs_v231_comparison_20251231.md`

---

## 📊 评估指标说明

### 主要指标

1. **平均收益**: Top10股票的平均收益率
2. **中位数收益**: Top10股票的中位数收益率
3. **最大收益**: 表现最好的股票收益率
4. **最小收益**: 表现最差的股票收益率
5. **胜率**: 盈利股票占比
6. **预测日平均涨幅**: 预测当日股票的平均涨幅
7. **追高数量**: 预测日涨幅>9%的股票数量（越少越好）

### 对比维度

- **收益表现**: 哪个模型预测的股票收益更高
- **稳定性**: 哪个模型的收益更稳定（中位数、最大/最小收益）
- **风险控制**: 哪个模型追高数量更少
- **胜率**: 哪个模型胜率更高

## 📝 注意事项

1. **数据获取**: 需要确保能访问Tushare API获取实际收盘数据

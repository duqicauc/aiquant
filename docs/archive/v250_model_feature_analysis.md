## 📊 一、特征数量对比

| 版本 | 特征数量 | 差异 |
|------|---------|------|
| v2.3.0 | 135个 | - |
| v2.5.0 | 102个 | **减少33个** |

### 特征减少的原因

1. **特征对齐机制**
   - v2.5.0在训练时进行了严格的特征对齐
   - 只保留正样本和负样本都存在的共同特征
   - 确保训练和预测时特征一致性

2. **移除的特征类别（33个）**

   **a) 市场相关特征（6个）**
   - `market_pct_chg`, `market_return_34d`, `market_volatility_34d`
   - `market_trend`, `excess_return`, `excess_return_cumsum`
   - **原因**: 预测时难以获取，且可能引入未来函数

   **b) 技术指标（18个）**
   - 乖离率: `bias_short`, `bias_mid`, `bias_long`
   - EMA指标: `ema_5`, `ema_10`, `ema_20`, `ema_60`
   - KDJ指标: `kdj_k`, `kdj_d`, `kdj_j`
   - 历史位置: `price_vs_hist_mean`, `price_vs_hist_high`, `volatility_vs_hist`
   - 其他: `obv`（保留`obv_calc`和`obv_trend`）、`is_limit_up`、`vol_ma5_ratio`、`vol_ma20_ratio`、`turnover_rate_f`
   - **原因**: 与现有特征重复或冗余

   **c) 风险特征（9个）**
   - 最大回撤: `max_drawdown_10d`, `max_drawdown_20d`, `max_drawdown_55d`
   - ATR: `atr_14`, `atr_ratio_14`, `atr_expansion`
   - 距高点天数: `days_from_high_20d`, `days_from_high_55d`
   - 恢复比例: `recovery_ratio_20d`
   - **原因**: 特征提取时可能未正确计算，或与现有特征重复

## 🧠 三、模型决策逻辑

### 3.1 核心决策因子（Top 7，占99.3%重要性）

1. **市值/流动性（33.85%）**
   - `circ_mv`（流通市值）- 24.34%
   - `total_mv`（总市值）- 9.51%
   - **作用**: 过滤小盘股，确保流动性

2. **RSI指标（40.77%）**
   - `rsi_6`（6日RSI）- 20.40%
   - `rsi_12`（12日RSI）- 14.65%
   - `rsi_24`（24日RSI）- 5.72%
   - **作用**: 判断超买超卖，避免追高

3. **均线特征（24.69%）**
   - `ma5`（5日均线）- 16.52%
   - `ma10`（10日均线）- 8.17%
   - **作用**: 判断短期趋势，识别突破信号

### 3.2 决策逻辑总结

v2.5.0模型的决策逻辑主要基于以下几个方面：

#### 1. 【市值/流动性筛选】- 最重要的因子（33.85%）
- 优先选择流通市值和总市值较大的股票
- 确保有足够的流动性，避免无法交易
- 过滤掉小盘股和流动性差的股票

#### 2. 【RSI超买超卖判断】- 核心验证因子（40.77%）
- 通过6日、12日、24日RSI综合判断
- 避免在超买区域追高
- 识别超卖后的反弹机会

#### 3. 【均线趋势判断】- 趋势识别（24.69%）
- 5日和10日均线判断短期趋势
- 价格相对均线的位置（price_vs_ma_*）
- 识别突破均线的信号

#### 4. 【价量配合验证】- 辅助验证
- OBV指标（obv_calc, obv_ma10）
- 价量匹配度（volume_price_match*）
- 确保上涨有成交量支撑

#### 5. 【动量/收益】- 动能指标
- 20日动量（momentum_20d）
- 多周期收益率（return_*）
- 识别上涨动能

#### 6. 【技术位置】- 空间指标
- 价格在通道中的位置（price_position_*）
- 距离支撑/阻力位的距离（dist_to_*）
- 支撑/阻力强度（support/resistance_strength）

#### 7. 【技术指标】- 辅助验证
- MACD（macd_dif, macd_dea）
- 波动率（volatility_*）

### 3.3 模型特点

1. **浅树结构（max_depth=3）**
   - 自动进行特征选择，只使用22个核心特征
   - 避免过拟合，提高泛化能力
   - 决策规则简单清晰

2. **高度依赖核心特征**
   - 前7个特征占99.3%的重要性
   - 模型决策主要基于市值、RSI、均线
   - 其他特征起辅助验证作用

3. **特征精简的优势**
   - 虽然特征数量减少，但保留了最有效的特征
   - 模型性能反而提升（AUC: 0.9987）
   - 训练和预测速度更快

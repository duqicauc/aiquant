# v2.5.0 模型优化方案

## 改进建议

### 1. 添加233日均线特征

**原因：**
- 233是斐波那契数列中的重要数字，在技术分析中被广泛使用
- 代表约11个月的长期趋势，能更好地判断股票所处的市场周期
- 与现有的短中期均线（5/8/10/20/34/55日）形成完整的多周期体系

**新增特征：**
```python
# 在特征提取中添加
ma_233d = close.rolling(233).mean()  # 233日均线
price_vs_ma_233d = (close - ma_233d) / ma_233d * 100  # 价格相对233日均线的位置
breakout_ma233 = (close > ma_233d).astype(int)  # 是否突破233日均线
```

**预期效果：**
- 帮助识别长期上升趋势中的股票
- 过滤掉处于长期下跌趋势的股票
- 提升模型对牛股的识别能力

### 2. 提高上市天数要求

**当前问题：**
- 最小上市天数：180天（约6个月）
- 质量评估发现：2个正样本天数不足（<30天）
- 无法计算233日均线（需要至少233天数据）

**建议调整：**
```yaml

  min_listing_days: 300  # 从180天提升到300天（约14个月）
  
# 原因：
# 1. 至少需要233天数据 + 额外缓冲
# 2. 过滤掉上市不足1年的新股（新股行为模式不稳定）
# 3. 确保有充足的历史数据计算各种技术指标
```

**影响分析：**
- ✅ 样本质量提升：过滤掉数据不足的样本
- ✅ 特征完整：能计算所有周期的技术指标
- ✅ 新股过滤：避免次新股的异常波动干扰
- ⚠️ 样本数量：可能减少约10-15%的正样本（但质量更高）

## 技术细节

### 233日均线计算示例

```python
def extract_features_with_ma233(df):
    """添加233日均线特征"""
    
    # 基础均线
    df['ma_233d'] = df['close'].rolling(233, min_periods=200).mean()
    
    # 价格位置
    df['price_vs_ma_233d'] = (df['close'] - df['ma_233d']) / (df['ma_233d'] + 1e-10) * 100
    
    # 突破信号
    df['breakout_ma233'] = (df['close'] > df['ma_233d']).astype(int)
    
    # 与233日均线的距离
    df['dist_to_ma233'] = (df['close'] - df['ma_233d']) / df['close'] * 100
    
    # 233日均线斜率（趋势方向）
    df['ma233_slope'] = df['ma_233d'].diff(5) / df['ma_233d'].shift(5) * 100
    
    return df
```

# v2.7.0模型预测稳定性评估指南

## 📋 评估目标

评估v2.7.0模型在2026年1月5日到1月15日期间的预测稳定性，包括：
1. Top50股票的平均概率变化
2. Top50股票的重叠率（稳定性）
3. Top10股票的重叠率
4. 全市场概率分布变化
5. 持续在Top50的股票（高稳定性股票）

---

## 🔧 操作步骤

### 步骤1: 生成1月5日到1月15日的预测结果

首先需要为这些日期生成v2.7.0模型的预测结果：

```bash
# 生成1月5日到1月15日的预测（排除周末）
python scripts/predict_v270_ensemble_top50.py \
  20260105 20260106 20260107 20260108 20260109 \
  20260112 20260113 20260114 20260115
```

**注意**：
- 需要网络权限访问Tushare API
- 需要确保Tushare token配置正确
- 可能需要较长时间（每个日期约1-2分钟）

**生成的文件**：
- `data/prediction/results/v270_ensemble_top50_YYYYMMDD.csv` - Top50预测结果
- `data/prediction/results/v270_ensemble_all_YYYYMMDD.csv` - 全市场预测结果

### 步骤2: 运行稳定性评估

生成预测结果后，运行评估脚本：

```bash
python scripts/evaluate_v270_stability.py
```

或者指定具体日期：

```bash
python scripts/evaluate_v270_stability.py \
  20260105 20260106 20260107 20260108 20260109 \
  20260112 20260113 20260114 20260115
```

### 步骤3: 查看评估结果

评估结果会：
1. **在控制台输出**：详细的稳定性分析
2. **保存到文件**：`data/prediction/evaluation/v270_stability_evaluation_20260105_to_20260115.md`

## 📊 评估指标说明

### 1. Top50平均概率变化

- **指标**：每日Top50股票的平均预测概率
- **稳定性判断**：
  - 变异系数 < 0.10：非常稳定
  - 变异系数 < 0.15：较稳定
  - 变异系数 < 0.20：中等稳定
  - 变异系数 >= 0.20：不稳定

### 2. Top50股票重叠率

- **指标**：相邻两个交易日Top50股票的重叠比例
- **稳定性判断**：
  - 重叠率 >= 70%：非常稳定
  - 重叠率 >= 60%：较稳定
  - 重叠率 >= 50%：中等稳定
  - 重叠率 < 50%：不稳定

### 3. Top10股票重叠率

- **指标**：相邻两个交易日Top10股票的重叠比例
- **说明**：Top10是核心推荐股票，重叠率越高说明模型越稳定

### 4. 全市场概率分布变化

- **指标**：全市场股票预测概率的均值、中位数、标准差等统计量
- **说明**：反映模型整体评分的一致性

### 5. 持续在Top50的股票

- **指标**：在整个评估期间持续出现在Top50的股票
- **说明**：这些股票是模型高度看好的标的，值得重点关注

## 🎯 稳定性评级标准

| 评级 | 条件 | 说明 |
|------|------|------|
| ⭐⭐⭐⭐⭐ 非常稳定 | 重叠率>=70% 且 变异系数<0.10 | 模型预测非常一致 |
| ⭐⭐⭐⭐ 较稳定 | 重叠率>=60% 且 变异系数<0.15 | 模型预测较为一致 |
| ⭐⭐⭐ 中等稳定 | 重叠率>=50% 且 变异系数<0.20 | 模型预测基本一致 |
| ⭐⭐ 较不稳定 | 重叠率>=40% | 模型预测变化较大 |
| ⭐ 不稳定 | 重叠率<40% | 模型预测不稳定 |

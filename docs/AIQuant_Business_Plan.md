**版本**：v1.0  
**日期**：2026年5月  
**定位**：面向散户投资者的量化数据分析工具（非投资咨询/非荐股）

## 一、执行摘要

AIQuant 是一款基于机器学习的**量化信号分析平台**，通过 5,882 维特征工程与 XGBoost 模型，对全市场 5,500+ 只 A 股进行概率分布计算，输出突破启动信号的历史回测统计与实时模型打分。

**核心主张**：把机构级量化研究能力，以 SaaS 形式普惠给个人投资者。

| 维度 | 概要 |
|------|------|
| **目标用户** | A 股散户投资者（10-500万资金规模）、量化爱好者 |
| **商业模式** | P1 订阅制 SaaS（¥99-999/月）+ P4 内容社群（¥365-2999/年） |
| **技术壁垒** | v3.0.0 模型（71 棵 XGBoost，5,882 维特征，120 日滚动窗口） |
| **数据资产** | 570 个交易日全市场 OHLCV 数据（2024.01-2026.05），覆盖 5,600+ 只股票 |
| **合规策略** | 明确定位"数据分析工具"，所有输出均为模型概率统计，附带完整免责声明 |
| **首年目标** | 5,000 名注册用户，500 名付费订阅用户，ARR（年度经常性收入）60 万元 |

## 二、市场痛点与机会

### 2.1 散户投资者的结构性困境

| 痛点 | 现状 | 代价 |
|------|------|------|
| **信息不对称** | 机构拥有 Level-2 行情、舆情 NLP、因子库；散户只有 K 线 + 股吧 | 决策质量差距大 |
| **情绪化交易** | 追涨杀跌、过度交易、无止损纪律 | 散户年化亏损率 20-40% |
| **工具门槛高** | Python/量化框架（Backtrader/Zipline）学习曲线陡峭 | 90% 散户无法自建策略 |
| **伪信号泛滥** | 短视频/直播荐股、付费群"老师"、技术指标收费软件 | 财产损失 + 时间浪费 |

### 2.2 市场规模

- **A 股个人投资者**：2.1 亿人（中国证券登记结算公司，2025 年末）
- **活跃证券账户**：约 5,000 万户（月交易 ≥1 次）
- **付费意愿人群**：约 300 万人（愿意为数据工具/课程付费）
- **TAM（可触达市场）**：300 万人 × ¥500/年 = **150 亿元**
- **SAM（可服务市场）**：量化分析工具细分市场 ≈ **15 亿元**
- **SOM（初期目标）**：首年 ARR 60 万 → 3 年 ARR 500 万

### 2.3 趋势红利

1. **AI 平民化**：ChatGPT 教育了市场，散户对"AI 选股"接受度大幅提升
2. **监管净化**：2024 年起"非法荐股"严打，正规数据分析工具稀缺
3. **降佣时代**：券商佣金战导致差异化服务需求上升，API 合作空间打开

## 三、产品定位与价值主张

### 3.1 定位声明

> **AIQuant 是一款 A 股量化信号分析工具。** 我们通过机器学习模型计算每只股票在下一交易日出现"突破启动"形态的概率分布，并提供历史回测统计、多因子诊断、组合跟踪等功能。**我们不提供买卖建议，不构成投资决策依据。**

### 3.2 三层价值

| 层级 | 功能 | 用户收益 |
|------|------|----------|
| **数据层** | 全市场实时/历史 OHLCV、5,882 维因子、基本面数据 | 节省数据收集与清洗时间 |
| **模型层** | XGBoost 概率打分、Top50 信号池、分箱分布图 | 获得机构级量化视角 |
| **认知层** | 模型逻辑解读、因子归因、历史胜率统计、课程社群 | 提升对市场的系统性理解 |

### 3.3 与"荐股软件"的本质区别

| 维度 | AIQuant | 荐股软件/群 |
|------|---------|-------------|
| **输出形态** | 概率分布 + 历史回测统计 | "买入 XX 股，目标价 XX" |
| **决策权** | 用户自主判断 | 被动跟随"老师" |
| **透明度** | 模型版本、特征维度、回测夏普率全公开 | 黑箱，无逻辑 |
| **合规边界** | 数据分析工具定位 | 涉嫌非法证券投资咨询 |
| **失败归因** | 用户理解模型局限，接受概率本质 | 亏损后归咎于"老师"或平台 |

## 四、技术壁垒与核心能力

### 4.1 模型体系 v3.0.0

| 指标 | 规格 |
|------|------|
| **算法** | XGBoost（梯度提升树） |
| **特征维度** | 5,882 维 |
| **树数量** | 71 棵 |
| **训练窗口** | 120 日滚动 |
| **样本定义** | 正样本（突破后 20 日涨幅 ≥15%）、负样本（涨幅 <5%）、困难负样本（涨幅 5-10%） |
| **校准方法** | Platt Scaling |
| **输出形态** | 概率值（0-1）+ 分箱分布 |

### 4.2 数据基础设施

| 组件 | 技术 | 规模 |
|------|------|------|
| **时序数据库** | ArcticDB（LMDB） | 307 万行 OHLCV，570 个交易日 |
| **缓存层** | SQLite | 22 万行近期日线/基本面 |
| **数据源** | Tushare Pro API | 全市场 5,500+ 只股票 |
| **预测存储** | CSV 归档 | 516 个历史预测文件（2026.01-05） |

### 4.3 护城河

1. **样本工程壁垒**：正/负/困难负样本的定义与动态配比（15-20%），直接影响模型区分度
2. **特征一致性**：训练→回测→生产使用同一套 `FeatureEngineer.compute_all_features()`，避免特征漂移
3. **版本化管理**：模型（v3.0.0）+ 样本（v295）+ 特征（v295）三重版本锁定，确保可复现
4. **数据资产壁垒**：570 天全市场数据持续积累，新进入者复制成本 >3 个月

## 九、合规与风险

### 9.1 合规边界（核心）

**红线**：根据《证券法》第160条、《证券投资顾问业务暂行规定》，**未取得证券投资咨询业务资格，不得向客户提供买卖建议**。

**AIQuant 的合规设计**：

| 维度 | 设计 |
|------|------|
| **产品定位** | "量化数据分析工具"，非"投资咨询" |
| **输出形态** | 概率值（0-1）+ 历史统计，无"买入/卖出/持仓"指令 |
| **用户协议** | 强制签署《免责声明》："本工具仅供数据分析参考，不构成投资建议" |
| **付费标的** | 软件服务费/数据服务费，非"投资收益分成" |
| **内容边界** | 社区内容仅限方法论讨论，禁止个股推荐、带单、晒单诱导 |

### 9.2 风险矩阵

# v2.5.x 预测脚本版本对比

## 📊 版本概览

所有v2.5.x版本都使用**v2.5.0模型**（包含233日均线特征、时间序列划分训练），区别在于预测逻辑和评分策略。

| 版本 | 脚本文件 | 基于 | 核心特点 | 适用场景 |
|------|---------|------|---------|---------|
| **v2.5.1** | `predict_v251_top10.py` | v2.3.1 | 双目标排序(50:50)，无惩罚 | 激进追涨 |
| **v2.5.2** | `predict_v252_top10.py` | v2.3.2 | 双目标排序(60:40)+惩罚机制 | **推荐，平衡稳健** |
| **v2.5.3** | `predict_v253_top10.py` | v2.3.3 | 双目标排序(60:40)+板块轮动 | 提前布局 |

---

## 🔍 详细对比

### v2.5.1 - 双目标排序版（激进）

**评分公式**:
```
final_score = 0.5 * 校准概率 + 0.5 * 预期收益
```

**特点**:
- ✅ 纯模型评分，无惩罚机制
- ✅ 等权重：概率和收益各占50%
- ❌ 可能选出当日涨幅过高的股票
- ❌ 追高风险较大

**适用场景**:
- 趋势明确的牛市
- 想要激进追涨的投资者
- 相信模型判断，不担心追高

**命令**:
```bash
python scripts/predict_v251_top10.py --date 20251231
```

---

### v2.5.2 - 追高控制版（推荐）

**评分公式**:
```
base_score = 0.6 * 校准概率 + 0.4 * 预期收益
final_score = base_score * penalty
```

**惩罚机制**:
| 条件 | 惩罚系数 |
|------|---------|
| 当日涨幅 > 15% | × 0.5 |
| 当日涨幅 10-15% | × 0.8 |
| 涨停但概率 < 0.8 | × 0.7 |
| RSI > 95 | × 0.8 |
| RSI > 90 | × 0.9 |
| 连续涨停 ≥ 3天 | × 0.6 |
| 连续涨停 ≥ 2天 | × 0.8 |

**特点**:
- ✅ **双目标排序**：0.6*校准概率 + 0.4*预期收益（更重视模型判断）
- ✅ 有效控制追高风险（多种惩罚机制）
- ✅ 过滤低流动性股票（成交额<3000万）
- ✅ 历史表现稳定

**适用场景**:
- 震荡市或不确定市场
- 追求稳健收益的投资者
- 想要控制追高风险

**命令**:
```bash
python scripts/predict_v252_top10.py --date 20251231
```

---

### v2.5.3 - 板块轮动版（布局）

**评分公式**:
```
base_score = 0.6 * 校准概率 + 0.4 * 预期收益  # 双目标排序
final_score = base_score * penalty * sector_adjustment
```

**板块调整**:
| 板块热度 | 调整系数 | 说明 |
|---------|---------|------|
| > 0.85（过热） | × 0.70 | 20日涨幅>30% |
| > 0.75（强势） | × 0.85 | 20日涨幅20-30% |
| > 0.60（启动） | × 1.05 | 20日涨幅10-20% |
| < 0.45（潜力） | × 1.10 | 放量但涨幅小 |

**特点**:
- ✅ **双目标排序**：0.6*校准概率 + 0.4*预期收益（与v2.5.2相同）
- ✅ 保留v2.5.2的追高惩罚
- ✅ 新增板块热度分析
- ✅ 降低过热板块权重
- ✅ 提升潜力板块权重
- ⚠️ 执行时间较长（需分析板块）

**适用场景**:
- 板块轮动明显的市场
- 想要提前布局的投资者
- 愿意等待轮动机会

**命令**:
```bash
# 基础版（不启用板块分析）
python scripts/predict_v253_top10.py --date 20251231

# 完整版（启用板块分析，耗时较长）
python scripts/predict_v253_top10.py --date 20251231 --enable-sector
```

## 📈 推荐策略

### 默认推荐：v2.5.2

**理由**:
1. **平衡稳健**：既重视模型判断，又控制追高风险
2. **历史验证**：v2.3.2逻辑已经过多次验证
3. **执行效率**：无需额外分析，速度快
4. **普适性强**：适合大多数市场环境

### 场景化推荐

| 市场环境 | 推荐版本 | 说明 |
|---------|---------|------|
| 牛市上涨 | v2.5.1 | 追涨策略，最大化收益 |
| 震荡市 | v2.5.2 | 稳健策略，控制风险 |
| 板块轮动 | v2.5.3 | 轮动策略，提前布局 |
| 熊市下跌 | v2.5.2 | 防守策略，严控追高 |

## 🎯 最终建议

1. 追高控制有效，减少高位接盘风险

4. 平衡了收益和风险

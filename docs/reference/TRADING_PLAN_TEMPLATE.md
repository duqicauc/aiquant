# 交易计划模板 - 固定目录结构

## 📋 说明

本文档定义了交易计划的**固定目录结构**，所有交易计划都应遵循此结构，确保格式统一，便于查阅和对比。

**重要**：目录结构固定后，不要随意修改，如需调整，需经过讨论和确认。

---

## 📁 固定目录结构

### 1. 基本信息（Header）

```
# 交易计划书 - YYYY年MM月DD日

**生成时间**: YYYY-MM-DD
**分析系统**: AIQuant vX.X.X
**分析师**: AI量化系统
**风险等级**: ⚠️ 风险等级
**预测日期**: YYYY-MM-DD
**数据来源**: 预测结果文件路径
```

### 2. 📊 执行摘要

**必含内容**：
- 快速决策表（表格形式）
- 核心要点（3-5条）

**格式要求**：
- 使用表格展示关键信息
- 使用列表展示核心要点

### 3. 📈 市场分析

**必含内容**：
- 整体市场环境分析
- 模型预测分析（如适用）
- 行业/板块分析（如适用）

**格式要求**：
- 分小节详细分析
- 使用数据支撑观点

### 4. 🎯 详细操作方案

**结构要求**：
- 每支股票一个独立章节
- 每个章节包含以下子章节：

#### 4.1 股票概况
- 股票代码、名称、行业
- 当前价格、预测日涨跌
- 模型预测概率

#### 4.2 模型预测详情
- 各子模型的预测概率
- 集成概率
- 模型一致性分析

#### 4.3 技术指标分析
- RSI、动量、波动率等关键指标
- 技术面评估

#### 4.4 风险评估
- 风险等级
- 风险点分析
- 风险控制措施

#### 4.5 操作策略
- 阶段一：观察建仓期
- 阶段二：分批建仓
- 阶段三：持仓管理
- 止盈止损位设置

#### 4.6 持仓周期建议
- 短期目标
- 中期目标
- 退出条件

#### 4.7 操作纪律
- 必须执行的操作
- 严禁操作的行为

### 5. 💰 组合管理

**必含内容**：
- 仓位分配表
- 组合风险控制
- 预期收益分析（最佳/正常/最差情况）

### 6. 📋 操作检查清单

**必含内容**：
- 盘前准备
- 集合竞价阶段
- 开盘前5分钟
- 上午时段
- 下午时段
- 收盘后总结

**格式要求**：
- 使用复选框格式 `- [ ]`

### 7. ⚠️ 风险提示与免责声明

**必含内容**：
- 主要风险（市场风险、流动性风险、操作风险、技术风险）
- 应对预案
- 免责声明

### 8. 📞 后续跟踪

**必含内容**：
- 每日复盘模板
- 持仓跟踪计划
- 下次调整信号

### 9. 💡 重要提醒

**必含内容**：
- 交易原则
- 成功关键
- 心态建设

### 10. 📝 总结

**必含内容**：
- 核心要点总结
- 操作建议
- 重要提醒

---

## 📝 使用说明

### 创建新交易计划

1. **复制模板结构**：按照上述目录结构创建新文档
2. **填写基本信息**：更新日期、系统版本等信息
3. **填充具体内容**：根据实际情况填写各章节内容
4. **保持格式一致**：使用相同的格式和风格

### 文件命名规范

```
trading_plan_YYYYMMDD.md
```

例如：
- `trading_plan_20260116.md`
- `trading_plan_20260117.md`

### 存放位置

```
docs/trading_plan_YYYYMMDD.md
```

# 基本面筛选功能使用说明

## 概述

基本面筛选功能用于在v2.7.0或v2.3.2选股器中筛选被错杀的优质公司，确保选到的股票具有良好的基本面。

## 筛选条件（v3版本：国九+红利+审计筛选）

1. **市值筛选**：market_cap在10-100亿之间
2. **财务筛选**：营业收入>1亿, 净利润>200万
3. **盈利能力筛选**：ROE>0, ROA>0

## 使用方法

### 1. v2.7.0模型预测

```bash
# 不使用基本面筛选（默认）
python scripts/predict_v270_ensemble_top50.py 20260116

# 启用基本面筛选
python scripts/predict_v270_ensemble_top50.py 20260116 --fundamental
```

### 2. v2.3.2模型预测

```bash
# 不使用基本面筛选（默认）
python scripts/predict_v232_top10.py --date 20260116

# 启用基本面筛选
python scripts/predict_v232_top10.py --date 20260116 --fundamental
```

### 3. 结合v2.3.2和v2.7.0模型

```bash
# 不使用基本面筛选（默认）
python scripts/combine_v232_v270.py --date 20260116 --strategy weighted

# 启用基本面筛选
python scripts/combine_v232_v270.py --date 20260116 --strategy weighted --fundamental
```

## 筛选逻辑

基本面筛选器会：

1. 从`daily_basic`接口获取市值数据
2. 从`fina_indicator`接口获取ROE、ROA数据
3. 从`income`接口获取营业收入、净利润数据
4. 对每只股票进行筛选，只保留满足所有条件的股票

## 筛选结果

筛选过程中会显示：
- 总股票数
- 通过筛选的股票数及比例
- 未通过筛选的股票数及比例
- 未通过的原因（市值过小/过大、营收不足、净利润不足、ROE不足、ROA不足等）

## 注意事项

1. **数据获取**：基本面筛选需要调用Tushare的财务数据接口，可能需要一定的积分要求
2. **性能影响**：启用基本面筛选会增加数据获取时间，因为需要为每只股票获取财务数据
3. **数据缺失**：如果某只股票的财务数据缺失，该股票会被标记为未通过筛选
4. **可选功能**：基本面筛选是可选的，默认不启用，需要时通过`--fundamental`参数启用

## 自定义筛选条件

如果需要修改筛选条件，可以在代码中修改`FundamentalScreener`的配置：

```python
fundamental_screener = FundamentalScreener(
    dm,
    config={
        'enabled': True,
        'market_cap_min': 100000,      # 10亿（单位：万元）
        'market_cap_max': 1000000,     # 100亿（单位：万元）
        'revenue_min': 1e8,            # 1亿（单位：元）
        'net_profit_min': 2000000,     # 200万（单位：元）
        'roe_min': 0,                  # ROE最小值（%）
        'roa_min': 0,                  # ROA最小值（%）
    }
)
```

# 25年数据样本目标分析

## 🎯 目标

**期望样本数**: 1,000 - 2,000 个正样本
**数据范围**: 25年（2000-2025年）
**股票数量**: 约4,962只

---

## 📊 当前条件分析

### 当前配置（优化后）
```yaml
future_return_threshold: 40   # 未来45天涨幅 > 40%
past_return_threshold: 20     # 过去60天涨幅 < 20%
volume_ratio_min: 1.2        # 量比 >= 1.2
volume_ratio_max: 4.0        # 量比 <= 4.0
min_signals: 2               # 至少2个预转信号
```

### 基于诊断结果的估算

**诊断数据**（100只股票，5年数据）：
- 总窗口数: 114,631个
- 找到样本: 39个
- 实际通过率: 0.034%

**扩展到25年全部股票**：
- 总窗口数: ~30,491,490个
- 优化后通过率（假设提升2.5倍）: 0.085%
- **预期样本数: ~25,900个**

---

## ⚠️ 问题分析

### 当前条件可能产生过多样本

根据估算，当前优化后的条件可能产生**约25,900个样本**，远超过目标的1,000-2,000个。

**原因**：
1. 25年数据量巨大（约3000万窗口）
2. 优化后条件相对宽松
3. 即使通过率很低，样本数也会很多

---

## 💡 优化建议

### 方案1：适度收紧条件（推荐）⭐

在保持样本质量的前提下，适度收紧条件：

```yaml
future_return_threshold: 45   # 从40%提高到45%
volume_ratio_min: 1.5         # 从1.2提高到1.5
volume_ratio_max: 3.5         # 从4.0降低到3.5
min_signals: 2                # 保持2个信号
```

**预期效果**：
- 通过率降低约30-40%
- 预期样本数: ~15,000-18,000个
- 仍可能略多，但质量更高

### 方案2：进一步收紧（如果方案1仍过多）

```yaml
future_return_threshold: 50   # 恢复到50%
volume_ratio_min: 1.5         # 保持1.5
volume_ratio_max: 3.0         # 恢复到3.0
min_signals: 2                # 保持2个信号
```

**预期效果**：
- 通过率接近原始值
- 预期样本数: ~10,000个
- 质量最高，但可能仍略多

### 方案3：分阶段筛选（推荐）⭐

**第一阶段**：使用当前优化条件筛选
- 预期样本: ~25,000个

**第二阶段**：在样本中进一步筛选
- 按涨幅排序，选择Top 10-15%
- 或按其他质量指标筛选

**优势**：
- 保留所有潜在样本
- 可以根据需要灵活调整
- 便于分析不同质量层次的样本

---

## 📋 推荐执行方案

### 推荐：方案1 + 方案3结合

1. **先使用方案1的配置**（适度收紧）
   ```yaml
   future_return_threshold: 45
   volume_ratio_min: 1.5
   volume_ratio_max: 3.5
   min_signals: 2
   ```

2. **运行筛选，查看实际样本数**

3. **如果样本仍然过多**：
   - 可以进一步收紧条件
   - 或在结果中按质量排序，选择Top样本

4. **如果样本不足**：
   - 可以适当放宽条件
   - 或降低预转信号要求到1个

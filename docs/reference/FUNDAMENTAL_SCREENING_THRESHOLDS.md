# 基本面筛选阈值推荐方案

## 市场背景

根据A股市场数据：
- **A股整体ROE**：多数公司ROE在0-10%区间，超过20%的连续水平极为稀少
- **A股整体ROA**：平均约在2-5%左右
- **市值10-100亿公司特点**：多为中小型企业，营业收入通常在5-50亿元，净利润在0.5-5亿元

## 推荐方案（三档）

### 方案1：保守方案（宽松筛选，保留更多股票）

**适用场景**：市场环境较差，希望保留更多候选股票

```python
config = {
    'market_cap_min': 100000,      # 10亿（万元）
    'market_cap_max': 1000000,     # 100亿（万元）
    'revenue_min': 3e8,            # 营业收入>3亿（元）
    'net_profit_min': 3000000,     # 净利润>300万（元）
    'roe_min': 2,                  # ROE>2%
    'roa_min': 1,                  # ROA>1%
}
```

**特点**：
- 筛选条件相对宽松
- 通过率较高（预计60-80%）
- 适合市场环境较差时使用

---

### 方案2：标准方案（推荐，平衡筛选）⭐

**适用场景**：正常市场环境，筛选"被错杀的优质公司"

```python
config = {
    'market_cap_min': 100000,      # 10亿（万元）
    'market_cap_max': 1000000,     # 100亿（万元）
    'revenue_min': 5e8,            # 营业收入>5亿（元）
    'net_profit_min': 5000000,     # 净利润>500万（元）
    'roe_min': 5,                  # ROE>5%
    'roa_min': 2,                  # ROA>2%
}
```

**特点**：
- 筛选条件适中，平衡质量和数量
- 通过率中等（预计30-50%）
- **推荐作为默认方案**

**理由**：
- **营业收入>5亿**：对于市值10-100亿的公司，市销率在2-20倍之间，相对合理
- **净利润>500万**：如果市值10亿，净利润500万，ROE约0.5%（偏低），但如果市值50亿，净利润500万，ROE约0.1%（太低）。实际上，如果要求ROE>5%，对于市值10亿的公司，净利润应该>5000万。但考虑到筛选的是"被错杀的优质公司"，500万是一个最低门槛。
- **ROE>5%**：高于A股平均水平，但不过于严格
- **ROA>2%**：接近A股平均水平，确保资产使用效率

---

### 方案3：严格方案（严格筛选，只保留优质股票）

**适用场景**：市场环境较好，希望只选择最优质的公司

```python
config = {
    'market_cap_min': 100000,      # 10亿（万元）
    'market_cap_max': 1000000,     # 100亿（万元）
    'revenue_min': 10e8,           # 营业收入>10亿（元）
    'net_profit_min': 10000000,    # 净利润>1000万（元）
    'roe_min': 8,                  # ROE>8%
    'roa_min': 3,                  # ROA>3%
}
```

**特点**：
- 筛选条件严格
- 通过率较低（预计10-20%）
- 只保留最优质的公司

**理由**：
- **营业收入>10亿**：确保公司有足够的业务规模
- **净利润>1000万**：确保公司有足够的盈利能力
- **ROE>8%**：明显高于A股平均水平，属于优质公司
- **ROA>3%**：高于A股平均水平，资产使用效率较高

## 动态阈值方案（根据市值调整）

如果希望根据市值动态调整阈值，可以使用以下方案：

```python
def get_dynamic_thresholds(market_cap):
    """
    根据市值动态计算阈值
    
    Args:
        market_cap: 市值（万元）
    
    Returns:
        阈值字典
    """
    # 市值范围检查
    if market_cap < 100000 or market_cap > 1000000:
        return None
    
    # 动态阈值
    # 营业收入：要求市销率<10（即营业收入>市值*10%）
    revenue_min = market_cap * 10000 * 0.1  # 市值（万元）*10000转为元，再*10%
    
    # 净利润：要求ROE>5%（即净利润>市值*5%）
    net_profit_min = market_cap * 10000 * 0.05  # 市值（万元）*10000转为元，再*5%
    
    return {
        'revenue_min': revenue_min,
        'net_profit_min': net_profit_min,
        'roe_min': 5,  # 固定ROE>5%
        'roa_min': 2,  # 固定ROA>2%
    }
```

**示例**：
- 市值10亿：营业收入>1亿，净利润>500万
- 市值50亿：营业收入>5亿，净利润>2500万
- 市值100亿：营业收入>10亿，净利润>5000万

---

## 行业差异考虑

不同行业的合理阈值差异很大：

### 轻资产行业（软件、互联网、服务）
- ROE可以要求更高（>10%）
- ROA可以要求更高（>5%）
- 营业收入要求可以适当降低

### 重资产行业（制造业、房地产、能源）
- ROE要求可以适当降低（>3%）
- ROA要求可以适当降低（>1%）
- 营业收入要求可以适当提高

### 建议
如果可能，可以根据行业动态调整阈值，但实现复杂度较高。**标准方案（方案2）是一个较好的折中方案**。

## 当前默认值问题

**当前默认值**：
```python
'revenue_min': 1e8,            # 营业收入>1亿
'net_profit_min': 2000000,    # 净利润>200万
'roe_min': 0,                 # ROE>0
'roa_min': 0,                 # ROA>0
```

**问题**：
1. ROE>0和ROA>0太宽松，几乎不筛选
2. 净利润>200万对于市值10-100亿的公司来说太低
3. 营业收入>1亿对于市值10-100亿的公司来说可能偏低

**建议**：使用**方案2（标准方案）**作为默认值。

## 最终推荐

### 推荐使用：方案2（标准方案）

```python
config = {
    'market_cap_min': 100000,      # 10亿（万元）
    'market_cap_max': 1000000,     # 100亿（万元）
    'revenue_min': 5e8,            # 营业收入>5亿（元）
    'net_profit_min': 5000000,     # 净利润>500万（元）
    'roe_min': 5,                  # ROE>5%
    'roa_min': 2,                  # ROA>2%
}
```

**理由**：
1. 平衡了筛选严格度和通过率
2. 符合"被错杀的优质公司"的定义
3. 高于A股平均水平，但不过于严格
4. 适合大多数市场环境

### 使用建议

- **正常市场**：使用方案2（标准方案）
- **市场较差**：使用方案1（保守方案）
- **市场较好**：使用方案3（严格方案）

```288:337:scripts/predict_v232_top10.py
def calculate_v232_score(cal_prob, expected_return_score, pct_chg, rsi_6, amount, consecutive_limit_up):
    """
    v2.3.2评分公式

    改进：
    1. 调整权重：0.6*校准概率 + 0.4*预期收益
    2. 追高惩罚：当日涨幅>15%，分数乘以0.5
    3. 涨停低概率惩罚：涨停但校准概率<0.8，分数乘以0.7
    4. RSI过热惩罚：RSI>95，分数乘以0.8
    5. 连续涨停惩罚：连续3天涨停，分数乘以0.6
    """
    # 基础评分：0.6*校准概率 + 0.4*预期收益
    base_score = 0.6 * cal_prob + 0.4 * expected_return_score

    penalty = 1.0
    penalty_reasons = []

    # 1. 追高惩罚：当日涨幅>15%
    if pct_chg > 15:
        penalty *= 0.5
        penalty_reasons.append(f"追高惩罚(涨幅{pct_chg:.1f}%)")
    # 涨幅10-15%轻度惩罚
    elif pct_chg > 10:
        penalty *= 0.8
        penalty_reasons.append(f"轻度追高(涨幅{pct_chg:.1f}%)")

    # 2. 涨停低概率惩罚：涨停但校准概率<0.8
    if pct_chg >= 9.8 and cal_prob < 0.8:
        penalty *= 0.7
        penalty_reasons.append(f"涨停低概率({cal_prob:.2f})")

    # 3. RSI过热惩罚
    if rsi_6 > 95:
        penalty *= 0.8
        penalty_reasons.append(f"RSI过热({rsi_6:.1f})")
    elif rsi_6 > 90:
        penalty *= 0.9
        penalty_reasons.append(f"RSI偏高({rsi_6:.1f})")

    # 4. 连续涨停惩罚
    if consecutive_limit_up >= 3:
        penalty *= 0.6
        penalty_reasons.append(f"连续涨停({consecutive_limit_up}天)")
    elif consecutive_limit_up >= 2:
        penalty *= 0.8
        penalty_reasons.append(f"连续涨停({consecutive_limit_up}天)")

    final_score = base_score * penalty

    return final_score, penalty, penalty_reasons
```

### 2.3 "市值/流动性"特征详解

#### 什么是"市值/流动性"？

**市值/流动性**是将两个相关概念合并在一起的分类，因为它们都用于评估股票的**可交易性**：

##### 1. 市值（Market Capitalization）

**市值** = 股票价格 × 股票数量

| 特征 | 全称 | 含义 | 计算公式 |
|------|------|------|---------|
| `circ_mv` | **流通市值**<br>(Circulating Market Value) | 可以自由交易的股票市值 | 股价 × 流通股本 |
| `total_mv` | **总市值**<br>(Total Market Value) | 所有股票的市值 | 股价 × 总股本 |

**区别**:
- **流通市值**：只计算可以在市场上自由交易的股票（不包括限售股、国有股等）
- **总市值**：计算公司发行的所有股票

**为什么重要？**
- ✅ **大盘股更稳定**：市值大的股票通常波动较小，不容易被操纵
- ✅ **流动性更好**：市值大的股票通常交易更活跃，买卖更容易
- ✅ **风险更低**：大盘股通常有更好的基本面支撑

##### 2. 流动性（Liquidity）

**流动性** = 股票交易的容易程度

| 特征 | 含义 | 作用 |
|------|------|------|
| `amount` | **成交额**<br>(Trading Amount) | 当日成交金额（单位：千元） | 衡量资金活跃度，成交额越大说明交易越活跃 |
| `turnover_rate` | **换手率**<br>(Turnover Rate) | 成交量占流通股本的比例 | 衡量股票换手频率，换手率高说明交易活跃 |

**为什么重要？**
- ✅ **避免无法交易**：流动性差的股票可能买不到或卖不出
- ✅ **减少冲击成本**：流动性好的股票，大额交易对价格影响小
- ✅ **价格更真实**：流动性好的股票，价格更能反映真实价值

##### 3. 为什么放在一起？

**市值和流动性高度相关**：
- 📈 **市值大 → 流动性好**：大盘股通常交易更活跃
- 📉 **市值小 → 流动性差**：小盘股可能交易不活跃，容易出现"有价无市"

**在量化交易中的作用**：
1. **筛选可交易股票**：确保选出的股票能够顺利买卖
2. **控制风险**：避免选择流动性差的股票，降低交易风险
3. **提高策略可行性**：确保策略在实际交易中可执行

#### 决策逻辑详解

- **作用**:
  - **市值筛选**：优先选择流通市值和总市值较大的股票（大盘股）
  - **流动性保障**：确保有足够的流动性，避免无法交易
  - **风险控制**：过滤掉小盘股和流动性差的股票，降低交易风险
  - **实际意义**：市值大的股票通常更稳定，不容易被操纵，交易更容易执行

**2. RSI超买超卖判断（40.77%）- 核心验证因子**

  - **这是模型的核心风险控制机制**

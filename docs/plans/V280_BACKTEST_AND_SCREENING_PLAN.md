# v2.8.0 回测对比 + 选股池方案

## 一、核心问题：特征对齐

**现状**：
- 训练数据 178 列，来自 `stk_factor_pro` 基础指标 + `enrich_features_v6.py` 自定义特征
- 当前预测脚本只计算了约 60 列基础特征，缺失突破/市场环境/交互特征
- **预测阶段特征 ≠ 训练阶段特征** → 模型在"盲人摸象"

**解决方案**：
- 基础指标：用 `stk_factor_pro(trade_date=date)` 批量获取（确保与训练一致）
- 自定义特征：复用 `enrich_features_v6.py` 中的计算逻辑
- 组合后生成完整 178 列特征向量

## 二、第一阶段：批量预测 + 特征对齐（~1.5 小时）

### 2.1 实现 `predict_v280_with_stk_factor.py`

功能：对指定日期范围，每天获取 `stk_factor_pro` + 计算自定义特征 + v2.8.0 预测

```
输入：日期范围（如 20260327 ~ 20260421）
输出：
  - data/prediction/results/v280_top50_{date}.csv
  - data/prediction/results/v280_top100_{date}.csv
  - data/prediction/results/v280_all_{date}.csv（全市场概率，用于分析）
```

**技术要点**：
- `stk_factor_pro` 单次获取全市场（trade_date 参数），约 1 次 API/天
- 自定义特征在 `stk_factor_pro` 数据基础上计算（突破强度、市场环境等）
- 批量特征提取优化（groupby + transform，~30 秒/天）

### 2.2 跑批量预测

- 约 18 个交易日

## 四、第三阶段：v2.8.0 作为选股池（长期方案）

### 4.1 定位

v2.8.0 不负责"最终买入决策"，而是负责**第一层筛选**：
- 从 5000 只全市场股票 → 压缩到 Top100 高概率候选
- 这些候选具备 breakout 的技术面基础条件

### 4.2 后续第二层信号（待实现）

在 v2.8.0 Top100 基础上，叠加更精细的筛选：

**候选方案 A：板块动量过滤**
- 只保留当日板块涨幅前 30% 的股票
- 利用板块效应提升突破概率

**候选方案 B：资金流向过滤**
- 用 `moneyflow` 或 `daily_basic` 中的资金流向数据
- 只保留主力净流入的股票

**候选方案 C：分时形态确认**
- 次日开盘后 30 分钟内观察分时图
- 只买入早盘放量上攻、回踩不破均线的股票

**候选方案 D：更精细的二级模型**
- 用 v2.8.0 Top100 的历史表现训练一个二级分类器
- 输入：v2.8.0 probability + 板块特征 + 资金流特征
- 输出：最终 Top10 买入名单

### 4.3 每日工作流程

```
收盘后：
  1. 跑 v2.8.0 → 输出 Top100 候选池
  2. 叠加第二层信号（板块/资金流/分时）→ 筛选到 Top10~20
  3. 写入次日交易计划

次日开盘：
  4. 按计划买入（开盘价或突破确认价）
  5. 盘中执行止损/MA5退出
```

## 六、关键风险

1. **stk_factor_pro 限流**：5120 积分 → 30次/分钟。如果按日期批量获取没问题（18天=18次调用）
2. **特征一致性**：必须验证 `stk_factor_pro` 的列名/参数与训练数据完全匹配
3. **市场环境变化**：3/28~4/22 只有约 18 个交易日，样本量小，回测结果可能波动大

**这意味着**: 不应盲目追求 0.98+ 的 AUC，而应在当前数据分布下优化**回测表现**和**泛化能力**。

## 二、根因分析汇总

### 2.1 为什么 v2.8.0/v2.9.1 训练指标下降？

| 根因 | 证据 | 影响 |
|------|------|------|
| **测试集变难** | v2.7.1 测试集时间跨度 4 年 vs v2.7.0 约 2 年 | AUC 绝对值下降 ~0.02-0.03 |
| **权重策略不当** | CatBoost 单模型 > 集成 | 集成效果被 XGB/LGB 拖累 |
| **特征排除** | v2.8.0+ 排除 6 个 breakout 特征 | 降低了起爆识别能力 |
| **Hard Negative 过度** | 比例 31.4%，阈值降至 15% | 正/负边界模糊 |
| **缺少校准** | v2.9.1 无 IsotonicRegression | 概率置信度虚高 |

### 2.2 为什么 v2.7.1-conservative 没超越 v2.7.0？

**不是因为改进无效，而是因为测试基准变了。**

如果在 v2.7.0 的测试集上跑 v2.7.1，可能会看到提升。但我们关心的是**未来实盘表现**，所以应该：
1. 用最新的、最长的测试集来评估
2. 关注回测胜率而非训练 AUC
3. 优化权重让最强的模型（CatBoost）主导

## 四、Phase 2: 权重策略优化（🔴 P0 - 当前重点）

### 4.1 问题定义

v2.7.1-conservative 中：
- CatBoost AUC = 0.9598
- XGBoost AUC = 0.9493（差距 -0.0105）
- LightGBM AUC = 0.9455（差距 -0.0143）

三等分权重让集成效果 **低于最强的单模型**，这是不合理的。

### 4.2 待实验的权重策略

| 策略 | 说明 | 预期效果 |
|------|------|----------|
| **A. CatBoost 主导** | 权重 0.5/0.25/0.25 或 0.5/0.3/0.2 | 让最强模型主导，减少拖累 |
| **B. 性能加权** | 权重 = AUC^k / sum(AUC^k)，k=2 或 3 | 放大强模型的影响力 |
| **C. 差异阈值法** | AUC 差异 >0.01 时动态分配，否则三等分 | v2.7.1 已部分实现，但阈值太宽松 |
| **D. Stacking** | 用 LR/XGB 学习最优组合权重 | 最复杂，但理论上最优 |

### 4.3 执行计划

```bash
# Step 1: 基于 v2.7.1 已训练的三个子模型，直接测试不同权重组合
# 无需重新训练子模型！

python scripts/evaluate_weight_strategies.py \
  --model-dir data/models/breakout_launch_scorer/versions/v2.7.1-conservative/model \
  --strategies equal,cbc-dominant,auc-squared,stacking
```

### 4.4 成功标准
- 至少有一种权重策略使集成 AUC > CatBoost 单模型（> 0.9598）
- Precision 和 Recall 的调和（F1）优于三等分

## 六、Phase 4: 回测评估（🟢 P2 - 最终决策）

### 6.1 为什么回测比训练指标更重要？

v2.7.0-ensemble 训练指标 0.982，但：
- 纯模型 Top10 次日胜率 50.2%
- 策略回测胜率仅 32.98%

**训练指标 → 模型选股能力**
**回测表现 → 实际赚钱能力**

两者之间存在巨大 gap（退出规则、摩擦成本、市场冲击）。

### 6.2 回测对比方案

| 对比组 | 模型 | 策略参数 |
|--------|------|----------|
| 基准组 | v2.7.0-ensemble | 固定5万/股, 4%止损, MA5退出 |
| 实验A | v2.7.1-conservative | 同上 |
| 实验B | v2.7.2-optimal（Phase 2最优权重） | 同上 |
| 实验C | v2.9.1-fixed（Phase 3修复版） | 同上 |

### 6.3 评估指标

| 指标 | 权重 | 说明 |
|------|------|------|
| 总收益率 | 30% | 最终赚钱能力 |
| 胜率 | 25% | 交易质量 |
| 盈亏比 | 20% | 风险收益效率 |
| 最大回撤 | 15% | 风险控制 |
| 夏普比率 | 10% | 风险调整后收益 |

### 6.4 生产切流决策

```
IF 实验B 或 实验C 的综合评分 > 基准组 + 5%:
    → 更新 current.json，切到新模型
    → 保留 v2.7.0-ensemble 作为 fallback
ELSE:
    → 继续用 v2.7.0-ensemble
    → 分析失败原因，进入下一轮迭代
```

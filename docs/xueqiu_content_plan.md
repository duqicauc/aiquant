## 第一篇：模型失败复盘贴

**标题**：我花 4 个月跑了一个 XGBoost 选股模型，结果还不如随机

**正文**：

去年底我训练了一个 v3.0.0 的 XGBoost 模型，5,882 维特征、71 棵树，听起来很唬人。

过去 4 个月（2026.01-05），每天用这个模型从全市场 5,500 只 A 股中选出 Top50 概率最高的股票，然后回测它们的次日表现。

**结论很残酷：**
- 含交易成本后，平均每笔收益 +0.03%
- 胜率 45.9%——也就是说超过一半的交易是亏的
- 跟闭着眼睛随机买 50 只股票，结果没有差别

**问题出在哪？**
我做了深度诊断，发现最致命的是：
1. 特征分布严重失衡——一个特征占模型 50% 的决策（至今没搞清楚它是什么因子）
2. 剩下的 5,881 维特征基本是噪声，大部分从未被使用
3. 模型本质上是"高波动率排序器"，只会选中科创板/创业板的小盘股，而不是真正预测方向
4. 3 月份市场调整期，模型大亏（月夏普 -1.65）

所以我现在暂停了所有商业化计划，回到最底层——重做特征工程，重构样本定义。

接下来 2-3 个月的目标很简单：跑出一个含交易成本后能稳定跑赢随机 50 只的模型。到时候再来雪球汇报进展。
